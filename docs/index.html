SportsHub shows live games and upcoming fixtures. Replays and highlights won’t appear in SportsHub, even if you enable them in your source addons.

Deploy to Cloudflare

New to Cloudflare?
  1. Create a Cloudflare account ↗ and verify your email if prompted.
  2. Return here and click Deploy to Cloudflare. Sign in and connect the GitHub account where Cloudflare should create the SportsHub repository.
  3. Choose a Worker name and follow the prompts. You can use a workers.dev address with the Workers Free plan.
  4. After deployment, find the HTTPS address under Workers & Pages → your SportsHub Worker.
  1. Open the deploy page and sign in to Cloudflare. Connect GitHub when prompted.
  2. In the secret fields, paste your configured AIOStreams manifest under AIOSTREAMS_MANIFEST_URL. For direct addons, use the matching source fields.
  3. Paste the value below into SPORTHUB_CATALOGS. If the field is missing, add it in your Worker's Settings → Variables and Secrets.
  4. Paste the language value below into SPORTHUB_STREAM_LANGUAGES. If the field is missing, add it in the same Worker settings.
  5. Deploy, then copy the HTTPS address of your new Worker.
Optional sports metadata API keys

SportsHub works with these fields blank. To add more schedule and team-logo coverage, create a free API-Sports account ↗ and copy your API key from its dashboard. You can also use a TheSportsDB v1 key ↗ if you have one.

Paste keys here to copy them into the matching Cloudflare secret fields. If a field is missing, add it as a Secret under your Worker’s Settings → Variables and Secrets. Keys entered here stay in this tab.
