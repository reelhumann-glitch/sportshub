Update SportsHub

  1. Find Worker
  2. Deploy update
  3. Verify

Find your existing Worker

  1. Open Cloudflare, go to Workers & Pages, and select your SportsHub Worker.
  2. Note the Worker name and its HTTPS address. Use this same Worker throughout the update so your Nuvio installation keeps working.
  3. Under Settings → Builds, check which GitHub repository and production branch are connected, if any.

Deploy to the same Worker

How do you deploy?

Cloudflare Builds

  1. If you set catalog or language preferences in Cloudflare, check the existing build’s deploy command before pushing. Add --keep-vars to its Wrangler deploy command so it preserves dashboard variables.
  2. Get the latest SportsHub release. If your GitHub copy offers Sync fork, you can use it to bring in the upstream changes. Otherwise, download the release source ZIP, copy its project files into a checkout of your connected repository, and keep any Worker-specific name, routes, and bindings in wrangler.toml.
  3. Push or merge the update into the connected production branch. Wait for the new deployment to succeed under Deployments.

Wrangler

  1. Update your local project from the latest SportsHub release. Keep any custom routes and bindings in wrangler.toml.
  2. From the updated folder, run npm ci. Sign in with npx wrangler login if needed.
  3. Replace EXISTING_WORKER_NAME with the name from step one, then run npx wrangler deploy --name EXISTING_WORKER_NAME --keep-vars in the same Cloudflare account. In Windows PowerShell, use npm.cmd and npx.cmd if needed.

Your existing AIOSTREAMS_MANIFEST_URL secret stays on the Worker. Keep the URL in Cloudflare Secrets.

Verify the update and reopen Nuvio

  1. Open the existing Worker address with /manifest.json at the end. Compare its version with the release you deployed. For example, release v0.3.0 reports 0.3.0.
  2. Refresh the SportsHub catalog in Nuvio or close and reopen the app. You can keep your existing Nuvio installation as long as the Worker address is the same.
