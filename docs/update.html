Update SportsHub

Update the same Cloudflare Worker to keep your existing Nuvio install and saved AIOStreams secret.

Get the latest release Open Cloudflare ↗
I deploy from GitHub
  1. Open your Worker’s Settings → Builds to find its repository and production branch. If you use dashboard variables for SportsHub preferences, add --keep-vars to the build’s Wrangler deploy command.
  2. Update that repository from the release source ZIP, keeping any custom Worker name, routes, and bindings in wrangler.toml. If your repository offers Sync fork, you can use it to bring in the upstream changes.
  3. Push to the connected production branch. Once Cloudflare deploys it, check the same link here again and reopen Nuvio.
I deploy with Wrangler
  1. Download and extract the release source ZIP. Carry over any custom routes and bindings in wrangler.toml.
  2. In that folder, run npm ci and sign in with npx wrangler login if needed. On Windows, use npm.cmd and npx.cmd if PowerShell blocks the commands.
  3. Run npx wrangler deploy --name EXISTING_WORKER_NAME --keep-vars, using the Worker name from your Cloudflare dashboard. Check the same link here again and reopen Nuvio.
