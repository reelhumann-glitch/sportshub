Update SportsHub

Open Cloudflare ↗ Download update ZIP
  1. In Cloudflare’s Workers & Pages, open your existing SportsHub Worker. Go to Settings → Builds and open its linked GitHub repository. If you set catalog or language preferences in Cloudflare, add --keep-vars to the existing build’s deploy command before updating.
  2. In that GitHub repository, use Sync fork if available. Otherwise, extract the update ZIP and use Add file → Upload files to upload its contents to the repository root. Keep your existing wrangler.toml for the 0.3.0 update. Commit the changes to the production branch shown in Cloudflare, or merge them into it.
  3. Wait for the deployment to succeed in Cloudflare. Check the same link here again and reopen Nuvio.

Updating the same Worker keeps your Nuvio install link and saved AIOStreams secret.

My Worker has no connected GitHub repository
  1. Download and extract the release source ZIP. Carry over any custom routes and bindings in wrangler.toml.
  2. In that folder, run npm ci and sign in with npx wrangler login if needed. On Windows, use npm.cmd and npx.cmd if PowerShell blocks the commands.
  3. Run npx wrangler deploy --name EXISTING_WORKER_NAME --keep-vars, using the Worker name from your Cloudflare dashboard. Check the same link here again and reopen Nuvio.
